# Benchmark 2026-11-22

dogu 0.3.0 (built from the branch before its version was bumped, so the tool reported itself as 0.2.1), Claude Code 2.1.330 (Claude Code), model `sonnet`, 3 runs of each task per setup. Servers: GitHub (official, hosted), Context7, DeepWiki.

- dogu folder, list in instructions: 57% fewer input tokens and 50% lower cost than loading the servers directly.
- dogu folder, "read the README": 44% fewer input tokens and 62% higher cost than loading the servers directly.
- dogu serve (code mode): 74% fewer input tokens and 47% lower cost than loading the servers directly.
